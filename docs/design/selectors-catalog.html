Principles

  1. One job per selector — two answers means two steps.
  2. Evidence in the frame beats asking someone to recall from scratch.
  3. Ontology first, text last: choice → scale → short → long.
  4. Always allow escape: Skip, Not sure, Other, None.
  5. Log the selector type with the answer so analytics stay honest.
