Release candidate **`77ccbc695`** (origin/main). Range: `v2026.10.23..77ccbc695`, about 100 merged PRs. Procedure: [`release-qa-program.md`](release-qa-program.md). Machine: one macOS arm64 host (12 cores) plus a Colima Postgres 18 stack; no Linux run.

## 3. Open and not covered

- **iOS build is shell-only.** The Safari extension is missing (`CI_BROWSER_EXTENSION_DIR` not set), so this build must not ship. This is the half of the iOS lane that needs a release in `CI-Browser-Extension`.
- **iOS launch screen still shows the old Companion Intelligence globe** (`Splash.imageset` not updated by #3252/#3253). Low.
- **Not run:** signed-in mobile flows (sync, keystore retry on a real device), new Android icons on screen, desktop app starting a real stack, tray menu clicks, a real TLS handshake through rustls 0.23.46, Safari extension contents, anything needing a Hub, PowerSync, or external services (Slack, Signal, Reddit, Google keys), live LLM behaviour with the small model.
- **#3257 follow-ups (Low):** revoking a grant does not return pre-approved asks to review (only matters if an operator undoes a deletion); the stalled-purge report has no error handling; a deployment with the purge switched off on purpose logs an error each hour; cron jobs and `connect_codes` can still touch an ended account (C-4); `geocode_cache` and `index_skips` can keep a deleted account's data (as before #3254); the stalled-purge report is log-only.
- **Performance, not a regression:** with real archives, a single process drains the `search-index` queue at about 25 jobs per minute.
- `desktop-e2e.yml` must be dispatched on the tag after publish (G6).
