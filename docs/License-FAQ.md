# License FAQ

### Can you summarize what Companion Memory's license allows?

The license grants free rights to use, modify, and redistribute Companion Memory source code for personal or nonprofit purposes. The intent is to stay permissive for those uses while limiting commercial abuse of Companion Intelligence products.

Companion Memory uses the [PolyForm Noncommercial License 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0). The full text is in [`LICENSE.md`](../LICENSE.md).

### What freedoms do you have as a Companion Memory user?

If you use Companion Memory for personal or nonprofit purposes, you can view, modify, and redistribute the source under the same license terms, subject to the PolyForm Noncommercial restrictions.

### Can I fork Companion Memory?

Yes. For noncommercial use, you can fork, modify, and redistribute Companion Memory under the same license.

### Can I contribute to Companion Memory?

Yes. Open a pull request on this repository.

### Can I sell Companion Memory?

No. Selling Companion Memory, including cloud-hosted instances, appliances that ship it, or paid support for those products, is not permitted. For commercial partnership questions, email partner@companionintelligence.com.

### Does this license apply to Companion Portal?

No. Companion Portal stays a separate commercial product. Companion Hub, Companion Capture, Companion Marketplace, Companion OS, and the Companion Browser Extension use the same PolyForm Noncommercial terms in their own repositories.

Portal add-ons are optional capacity. They do not buy you the right to run Memory. Memory is already free to run for personal and nonprofit use under this license.
